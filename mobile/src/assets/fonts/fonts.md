# Fonts fayllari

Quyidagi font fayllarini yuklab oling va shu papkaga joylashtiring:

## Kerakli fontlar:

1. **SF-Pro-Display-Regular.ttf** - Asosiy matnlar uchun
2. **SF-Pro-Display-Medium.ttf** - Sarlavhalar uchun
3. **SF-Pro-Display-Bold.ttf** - Qalin matnlar uchun

## Yuklab olish manzillari:

- Apple SF Pro: https://developer.apple.com/fonts/
- Google Fonts: https://fonts.google.com/

## Alternativ fontlar:

Agar yuqoridagi fontlar bo'lmasa, quyidagilarni ishlating:
- Roboto
- Open Sans
- System default
